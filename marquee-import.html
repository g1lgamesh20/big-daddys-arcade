👾 Marquee Map Importer

This tool runs entirely in your browser. Paste a batch of iScored GameID / GameLogo records and download a sanitized mapping file. Nothing you paste here is sent to GitHub, iScored, or any server by this page.

Important: Use only the JSON response containing game records from iScored Settings → Games. Never paste cookies, account tokens, passwords, or HAR files into this tool.
